# Botón 4 antes del inventario (Fabric 1.21.11)

Al apretar la tecla del inventario, el mod presiona el botón 4 del mouse y un tick después se abre el inventario.

## Cómo conseguir el .jar con GitHub
1. Subí el contenido de esta carpeta a un repositorio (en la raíz deben verse build.gradle, settings.gradle, src y la carpeta oculta .github).
2. Pestaña **Actions** -> esperá que termine "Compilar mod".
3. Bajá el artefacto **boton4-mod** (zip con el .jar).
4. Copiá el .jar (el que NO termina en `-sources`) a la carpeta `mods`.

## Requisitos
- Minecraft 1.21.11 con Fabric Loader 0.18.1 o superior
